# TubeFlip Cast — PWA

Application progressive web installable sur Android. Publication dans un sous-dossier du dépôt GitHub Pages existant pour ne modifier aucune autre application.

## Fonctions
- Coller un lien YouTube (vidéo, playlist, Shorts) et le transformer en URL yout-ube.com.
- Recherche par titre via services publics Invidious (disponibilité et CORS non garantis) ou API YouTube avec clé personnelle.
- Lecteur intégré yout-ube.com (peut refuser l'intégration) et lecteur officiel de secours.
- Historique et favoris sur le téléphone.
- Accès au Cast via l'application YouTube ; sélection de récepteur via le SDK Cast si compatible. La connexion à un récepteur ne diffuse pas automatiquement une page yout-ube.

Installation : ouvrir le lien HTTPS de ce dossier dans Chrome Android puis menu ⋮ > Ajouter à l'écran d'accueil / Installer.

Aucune affiliation avec YouTube ou Google. L'application ne contourne pas les restrictions de lecture ou d'intégration.
